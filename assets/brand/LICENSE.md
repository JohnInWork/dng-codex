# Логотип студии / Studio logo

- `studio-logo.png` — логотип студии Ивана, прислан им 05.10.2026 для заставки
  при запуске игры («из темноты выводим лого… через 3 секунды показываем меню»).
  Переведён в оттенки серого без изменения рисунка (исходник был RGBA 1024×1024,
  полностью непрозрачный, чёрно-белый), чтобы весить вдвое меньше; почти чёрный
  шум фона (яркость 1–12 из 255) доведён до чистого чёрного, иначе на чёрной
  заставке проступал квадрат картинки.

Права на логотип принадлежат владельцу студии. Это не CC0 и не часть наборов
библиотеки: брать его в другие проекты без разрешения нельзя.
